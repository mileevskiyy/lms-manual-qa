# Homework Submission Checklist

## Text answer
- [ ] Отправка только с текстом
- [ ] Отправка с текстом и файлом
- [ ] Пустой текст + без файлов
- [ ] Только пробелы
- [ ] Многострочный текст
- [ ] Спецсимволы
- [ ] Emoji
- [ ] Очень длинный текст

## Attachments
- [ ] PDF
- [ ] DOCX
- [ ] JPG
- [ ] PNG
- [ ] Unsupported EXE
- [ ] Corrupted file
- [ ] Duplicate file
- [ ] Long filename
- [ ] Filename with spaces
- [ ] Filename with non-Latin characters

## File count boundaries
- [ ] 1 file
- [ ] 4 files
- [ ] 5 files
- [ ] 6 files

## File size boundaries
- [ ] 9.9 MB
- [ ] 10 MB
- [ ] 10.1 MB

## Submission flow
- [ ] Status becomes Submitted
- [ ] Timestamp is shown
- [ ] Data persists after refresh
- [ ] Teacher sees submission
- [ ] Teacher can open attachments

## Editing
- [ ] Edit text before grading
- [ ] Add file before grading
- [ ] Remove file before grading
- [ ] Changes persist
- [ ] Editing blocked after grading

## Error handling
- [ ] Network interruption
- [ ] Server 4xx response
- [ ] Server 5xx response
- [ ] Clear user-facing error message
- [ ] No duplicate submission on double click
