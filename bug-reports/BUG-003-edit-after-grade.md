# BUG-003 — Student can edit homework after grading

**Severity:** Critical/Major depending on product rules  
**Reproducibility:** 5/5

## Preconditions
Homework has already been graded by a teacher.

## Steps
1. Log in as the student.
2. Open graded homework.
3. Edit answer text.
4. Save changes.

## Expected Result
Editing is disabled after grading.

## Actual Result
The student can change the submitted answer after receiving a grade.
