# LMS Manual QA Portfolio

Учебный QA-проект, моделирующий тестирование LMS для учеников, преподавателей и кураторов.

## Цель проекта

Показать практические навыки Junior QA Engineer:

- анализ требований;
- создание чек-листов и тест-кейсов;
- тест-дизайн;
- оформление баг-репортов;
- regression / smoke / retest;
- mobile & cross-browser testing;
- техническое расследование через DevTools;
- подготовка release test report.

> Проект является учебным портфолио и не содержит данных реальной компании.

## Тестируемый модуль

Модуль сдачи домашнего задания в LMS.

Основные требования:

1. Ученик может отправить текстовый ответ.
2. Можно прикрепить до 5 файлов.
3. Максимальный размер одного файла — 10 MB.
4. Разрешённые форматы: PDF, DOCX, JPG, PNG.
5. Нельзя отправить пустую работу без текста и файлов.
6. После успешной отправки статус меняется на `Submitted`.
7. Преподаватель должен видеть отправленную работу.
8. До выставления оценки ученик может редактировать работу.
9. После выставления оценки редактирование недоступно.
10. Основные сценарии должны работать в Chrome, Safari и на iPhone Safari.

## Структура

- `requirements/` — требования и вопросы к аналитике
- `checklists/` — smoke, regression и feature checklists
- `test-cases/` — подробные тест-кейсы
- `test-design/` — Boundary Value Analysis и Equivalence Partitioning
- `bug-reports/` — примеры качественных баг-репортов
- `mobile-testing/` — browser/device matrix
- `exploratory-testing/` — exploratory testing charter
- `reports/` — пример release test report
