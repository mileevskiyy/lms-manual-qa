# Exploratory Testing Charter

**Mission:** Investigate risks around homework submission under unstable and unusual user behavior.

**Timebox:** 45 minutes

## Focus areas
- slow/offline network
- double click / repeated actions
- refresh during upload
- background/foreground mobile browser
- duplicate attachments
- long text
- browser back/forward navigation

## Evidence to collect
- screenshots
- video
- DevTools Network requests
- Console errors
- exact reproduction frequency
